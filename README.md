# Booking & Cancellation Analysis

## Project Overview

This project analyzes hotel bookings and cancellations using Python, Pandas and Streamlit.

The objective is to identify booking patterns, cancellation behavior and factors that may affect hotel revenue and occupancy.

## Tools

- Python
- Pandas
- Streamlit
- CSV
- Visual Studio Code

## Project Files

- `booking_app.py`: Interactive Streamlit application.
- `booking_cancellation_analysis.py`: Python analysis script.

## Main Features

- Analysis of total bookings.
- Analysis of cancelled and non-cancelled bookings.
- Calculation of the cancellation rate.
- Analysis of booking patterns.
- Interactive data visualization.
- User-friendly dashboard.
